# 华为素材审核要求：执行清单

来源：[华为开发者联盟·杂志锁屏素材审核规范](https://developer.huawei.com/consumer/cn/doc/content/zazhisuoping-scsh-0000001318654366)。2026-10-13在浏览器直接打开并读取正文，页面显示更新时间2025-11-26 17:20。普通选题直接使用本地要点，不逐批重开官网。用户要求更新、收到新审核反馈、发现规则变化或实际提审需要确认最新版时才在线复核并更新本文件。不得冒称本批已在线核验，也不因普通选题没重开网页就标“最新规范待复核”。完整规范优先。用户偏好不是官方条款。

## 基础要求

| 项目 | 平台要求及应用方式 |
|---|---|
| 图片规格 | JPG，每图1M以内；手机1440×2560；折叠屏2934×3306；PAD竖1600×2560、横2560×1600；终端变化可能调整规格 |
| PAD裁切 | 四边各有100像素裁切；横竖屏使用同一图的相应效果，保证阅读连续 |
| 构图 | 主体在安全区域、居中偏上且突出；不单调无重点，也不堆叠复杂。安全区示意应直接查看官方图，不能凭文字猜坐标 |
| 视觉 | 清晰、处理自然，避免大量虚化/过度渲染、极端亮暗或刺目大色块；人物姿态表情自然 |
| 叠加信息 | 不浮叠LOGO、水印、文字等；节日、节气、专题等特殊场景有例外，不能扩展成一般许可 |
| 文案 | 标题≤10字、锁屏文案≤44字，标点、空格、版权等均计入；语言准确、通顺、有温度；引用需注明来源 |
| 一致性 | 标题、文案、图片、落地页互相匹配，不能以夸张错配诱导点击；图中具体地点必须与文字对应 |
| 落地页 | 主题聚焦、有内容、阅读与UI简洁，需作者名和头像；不私插导流联系方式、营销网址、二维码，不用弹窗/插屏干扰 |
| 来源 | 转载合规资质单位发布的信息，注明来源、原作者、原标题及编辑真实姓名等，保证可追溯，不歪曲原意 |

本用户更严格的策划限长：旅行/萌宠标题≤7字符，其余≤10，副标题≤25。内容摘要是编辑选题材料，不能直接塞入44字锁屏文案。选题信息链接是内部核实入口，正式落地页是否能展示、如何署名另行审核，不能把核验链接变成营销导流。

## 通用筛查

适用于图片、标题、文案、落地页。筛查违法内容及虚假信息、政治元素歪曲娱乐化、宗教元素、祭拜/迷信及涉及死亡等负面民俗元素、赌博/烟草/毒品元素、可能造成生理不适的事故灾难等负面画面。酒不能作为主视觉或露酒标；未成年人正面肖像不露出、不作为主视觉；竞品产品及关联事件禁止涉及，竞品范围与华为所有在售产品有关；避免争议人物/事件/地标，保持积极价值观。

“竞品”具体名单会变化，按当时在售产品与关联主体核查；不能将所有汽车或所有科技品牌一概归为竞品，也不能只凭未出现在旧名单就放行。

## 场景筛查

- 旅行：排除主权争议/不明确地点的风光，图中地点与文字一致。
- 汽车：避开争议品牌，不做明显广告，如销售额榜、排行榜。
- 明星：重点当红一二线艺人，避开负面新闻；不做性感挑逗/软色情图，不做艺人打榜。
- 科技：不做品牌新机或性能宣传性质的广告。
- 动物：表情适宜、外形不令人不适、无血腥。幽默标题不能靠恐惧、受伤或虐待图片兑现。
- 体育：注意时效，动作舒展，避免痛苦表情、过多裸露。
- 时尚/生活：避免怪诞不健康形象和摆卖产品；家居装饰避免太暗怪异、争议敏感物件及边缘造成屏幕破裂错觉的线条。
- 动漫：关注服装、姿态的性暗示/低俗导向与武器主视觉等要求；不选择涉及身份群体贬损或歧视的内容，对平台边界不明确的素材标待审核。
- 插画/艺术：避免模糊粗糙、主题不清、低幼、软色情及伦理争议内容。
- 美食：画面不引起不良联想，倡导健康饮食，关注官方列举的生肉、酒、海鲜等限制。

选题阶段先判断题材与图片方向是否有可行合规方案；正式制作再实测文件尺寸、大小、安全区、作者署名、图片授权和页面体验。不能在只读一张预览后宣称平台审核通过。
