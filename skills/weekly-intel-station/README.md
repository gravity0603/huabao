# weekly-intel-station

当前版本：**v1.3.0**（2026-09-03）

华为杂志锁屏「一周情报站」栏目 Skill。

每周把近一周的公开热点加工成 5 条适合华为安卓用户阅读的轻资讯，固定顺序为：

1. 财经热点
2. 生活出行
3. 趣味谈资
4. 健康养生
5. 科技新知

核心原则：不做资讯搬运，做新闻的二次加工。每条内容都要兼具事实依据、实用价值和轻松谈资。

## 主要规格

- 标题：通用不超过10字；实际品类为旅行/萌宠时不超过7字；先保证自然、完整，再计字数
- 副标题：20 字左右，硬上限 25 字
- 正文：不超过 150 字，目标 120-150 字
- 信息源：实际打开的官方或权威媒体公开新闻，附完整 `https://` 链接
- 原子卡：栏目槽位、平台/风格品类、内容主题、呈现格式、对象、事实、来源等级/日期、确定性、首图证明、至少3种内页画面、主钩子、用户收益、风险和 H/R/B
- 质量门槛：正式条目≥75分，本期优先选择≥85分候选；硬门槛失败不可用分数抵消
- 选题基调：正面中性、实用、有品位、科技感
- 禁止：负面、灾难、恐慌、公序良俗风险、变态猎奇及来源不明的新闻

财经新闻可以覆盖黄金、股市、居民消费政策和消费避坑，但不做个股推荐、涨跌预测、投资建议或恐慌性行情渲染。台风等天气新闻只做官方预警与出行服务提醒，不渲染灾害伤亡和损失。

## 安装

将本仓库根目录安装为 `skills/weekly-intel-station/`，确保目录内包含：

```text
weekly-intel-station/
├── SKILL.md
├── README.md
├── CHANGELOG.md
├── evals/
│   └── evals.json
└── references/
    └── knowledge-base.md
```

使用时可直接说：

- 「出一周情报站」
- 「出情报站」
- 「整理本周热点」
- 「做一期一周信息差」
- 「每周新闻周报」

Skill 会读取 `SKILL.md`、栏目知识库和 `huabao-content-planner` 的共享治理契约与十品类风格手册。默认检索近7天；用户指定范围优先。每条先建立新闻原子卡，完成确定性、画面、单一钩子、用户收益、H/R/B 与100分质量复核；R 覆盖不足或总分低于75时不作为正式成稿。

## 文件说明

- `SKILL.md`：唯一运行入口，包含触发规则、工作流、红线和输出契约
- `references/knowledge-base.md`：栏目专属知识库、选题池、来源标准、措辞风险与历史样例
- `evals/evals.json`：方向路由、确定性、标题副标题分工和质量门槛回归场景

## 维护

当前版本：v1.3.0。修改栏目规则时，先更新 `SKILL.md`，再同步 README、评测、版本号和 `CHANGELOG.md`；栏目专属知识变化时再更新 `references/knowledge-base.md`。不要创建第二份 `SKILL.md` 或第二份栏目主知识库。
