## 一、栏目规格速查

| 字段 | 规格 |
|------|------|
| 期次 | 每周 1 期，固定 5 条 |
| 顺序 | 财经→生活出行→趣味→健康→科技（固定，不重排） |
| 标题 | 通用≤10字（含标点）；实际品类为旅行/萌宠时≤7字 |
| 副标题 | 20 字左右（15-20 字最佳，硬上限 25） |
| 正文 | ≤150 字（目标 120-150，一段式） |
| 信息源 | 官方/权威媒体公开新闻，完整 `https://` 链接 |
| 封面标题 | 一周情报站（5 字，固定） |
| 封面副标题 | 5 条新鲜事，抹平一周信息差（13 字，固定） |

产出前逐条核字数：标题 >10、副标题 >25、正文 >150 均为硬违规。

## 二、华为用户画像与内容基调

- **目标人群**：华为安卓系统用户，成熟商务/品质生活人群（25-45+ 为主）
- **消费场景**：锁屏滑动，黄金 0.5-1 秒注意力窗口
- **数据依据**（huabao 知识库）：科技品类 CTR 天花板 30.95% 全场最高但流量池小，适合收尾知识条；座驾品类实测＝出行生活科普；动物/旅行是流量最大品类（趣味条负责轻松感）
- **基调**：有用 + 有趣 + 正能量；拒绝猎奇惊悚、负面渲染、贩卖焦虑、低俗哗众
- **每条三问**：对华为用户有什么用？有没有谈资？读起来是否舒服？

## 三、五方向选题池与写作模板（新顺序）

> 2026-08-13 用户确认排序：1 财经 → 2 出行 → 3 趣味 → 4 健康 → 5 科技。财经条在第一位，读者第一眼看到，务必稳、实用、有信息量。

### 3.1 财经热点（第 1 位，头条第 1 条）
- **选题池**：
  - 黄金：金价变动新闻（以事实报道角度）、黄金冷知识
  - 股市：新股发行/上市、重大政策、指数事件（以事件报道角度）
  - 居民消费政策：以旧换新、消费券、税费优惠、民生收费调整等
  - 消费避坑：政府/权威机构发布的消费提醒、维权指南
- **红线**：❌ 个股/基金推荐、涨跌预测、恐慌性行情渲染（"暴跌/抄底/崩了"）、投资建议、金钱符号；股市/黄金以「事件、政策、科普冷知识」角度做，事实中性，不做预测
- **模板**：政策/事件 → 对普通人的实际影响 → 怎么用（避坑/省钱/了解）
- **示例角度**：金价为何创历史新高（科普机制）；新股民入门冷知识；消费品以旧换新怎么申请

### 3.2 生活出行（第 2 位，实用担当）
- **选题池**：
  - 油费/燃油费：油价、机票燃油附加费调整（便民事实报道）
  - 交通新规：以官方发布为准（铁路/民航/交管）
  - 出行避坑和提醒：购票技巧、假期出行提示、车站机场服务
  - 天气影响：台风、暴雨等影响生活和出行的天气新闻（官方预警/服务提醒角度）
- **红线**：天气类以**官方预警/服务提醒**正面基调做（台风来了怎么应对、对出行有什么影响）；❌ 不渲染灾害、伤亡、损失，不制造恐慌；避开国产新能源品牌与电车话题、不做商业推荐
- **模板**：新规/调整 → 对用户的具体影响 → 怎么办
- **示例角度**：燃油附加费下调；台风临近出行提醒（官方渠道）；铁路新服务上线

### 3.3 趣味谈资（第 3 位，轻松担当）
- **选题池**：有趣的动物/宠物（猫狗为主）、旅行奇观、艺术趣闻（文物/名画/博物馆）、正向全球奇闻、科普向冷知识
- **红线**：不做动物保护争议、灾害相关趣闻、变态猎奇；艺术方向不做学术化赏析，聚焦"好玩/反差/冷知识"
- **模板**：有趣热点 → 一句话亮点 → 为什么有意思（可带公益落点）

### 3.4 健康养生（第 4 位，关怀担当）
- **选题池**：
  - 体育：运动健身知识、热门赛事资讯（避开奥运/世界杯字眼）、运动员正向故事
  - 饮食：营养常识、时令饮食、健康饮食误区
  - 育儿：儿童成长、科学育儿、开学/暑期健康
  - 通用：季节养生、睡眠/运动科学、体检知识、健康误区澄清
- **红线**：不做医疗建议/承诺（禁「治疗/根治」）、不推保健品药品、不用未证实偏方、不制造健康焦虑（含育儿焦虑）
- **模板**：本周健康话题 → 科学解释 → 可执行小建议

### 3.5 科技新知（第 5 位，收尾担当）
- **选题池**：知识类科普、天文/宇宙/航天新发现、科技突破、重大奖项（诺贝尔奖等）
- **红线**：不出现品牌名/公司名（转「科学家/研究人员/相关部门」）；禁"颠覆人类"式夸张；不做预测性承诺；奖项表述须准确（机构、年份、人物）
- **模板**：本周新发现 → 一句话讲清原理 → 对普通人有什么用/为什么值得知道
- **数据参考**：宇宙/天文类问句标题 CTR 极高（历史天花板 30.95%，如"黑洞也会挑食？"）

## 四、官方权威来源标准

只采用以下层级来源（按优先级）：
1. 官方机构：政府网站（如 .gov.cn）、部委公告、官方发布会（卫健委/商务部/铁路部门/气象部门等）
2. 中央权威媒体：新华社/新华网、央视新闻、人民日报系（人民网/证券时报等）
3. 权威机构/学术媒体：中科院（cas.cn）、科学网、权威科研机构官网
4. 省级权威媒体：省级日报/省级政府网（作为地方新闻来源可用，注明机构）

**拒绝**：来源不明的自媒体、论坛帖、短视频营销号、境外敏感媒体（如大纪元、美国之音等）；含品牌软文嫌疑的来源。

检索技巧：WebSearch 时限定 `site:gov.cn` 或官方媒体域名，或加"新华社/央视/发布"等关键词；优先用搜索摘要做线索，再实际打开原文核验。

## 五、措辞与驳回风险

来自用户反馈与审核实践，成稿前逐条对照：

| 风险 | 说明 | 对策 |
|------|------|------|
| 股市焦虑 | "暴跌/抄底/崩了"等恐慌渲染、个股推荐 | 只做事件/政策/科普角度，事实中性 |
| 负面渲染 | "退款难、商家关门失联"等消费乱象 | 改为正面引导："怎么选才稳妥/先看这几点" |
| 灾害恐慌 | 台风/暴雨渲染伤亡损失 | 官方预警+应对建议的服务性表述 |
| 猎奇措辞 | "生态杀手""放祸"等惊悚化 | 改中性科普："长多大/留在鱼缸里才对它好" |
| 金钱符号 | 图片/文案出现 ¥、$、货币符号 | 用"元"或"数十元"文字表述，不用符号 |
| 品牌名 | 企业名、产品名（含科技公司） | 转"科学家/研究人员/相关部门" |
| 医疗承诺 | "治疗/根治/预防某病" | 只做生活方式科普，不承诺疗效 |
| 育儿焦虑 | "别人家孩子"式比较、恐吓式育儿 | 正面科学建议 |
| 绝对词 | "必看/最全/震惊" | 标题直白陈述事实 |
| 疑问句无问号 | 疑问句标题不带"？" | 疑问句必须带问号 |
