# 一周情报站（Weekly Intel Station）

不做资讯搬运，做新闻的二次加工。每条都要回答：对华为用户有什么用？有没有谈资？读起来是否舒服？

## 启动与时间规则

每期先读：

1. 安装后从本 Skill 目录解析`../huabao-content-planner/references/selection-governance.md`；
2. 同目录`category-style-playbook.md`中与五个方向相符的品类章节；
3. 本 Skill 的 `references/knowledge-base.md`；
4. 用户当前提供的素材、H 已做表、R 上传表与往期周报。

默认检索近 7 天，符合栏目“周报”定位；用户当次给出“近三天”“近两周”“7月”或截止日时，必须覆盖默认范围。目标上线日和至少 30 天的 H/R/B 去重窗口独立计算；近期数据未覆盖窗口时，该条只能是待补数据草案。

## 硬性规格与固定顺序

| 字段 | 规格 |
|---|---|
| 标题 | 通用≤10字；实际品类为旅行/萌宠时≤7字，先保证自然完整再计数 |
| 副标题 | 15–20 字优先，≤25 字 |
| 正文 | ≤150 字，一段式 |
| 来源 | 已打开核验的官方/权威 HTTPS 链接 |

每期固定：1 财经热点 → 2 生活出行 → 3 趣味谈资 → 4 健康养生 → 5 科技新知。某方向没有合规候选时宁可空位，不降低来源、红线、风格或去重门槛。

## 六条硬闸

1. 正面中性，不做灾害、恐慌、低俗或负面舆情；
2. 只用官方、中央/地方权威媒体或权威机构；
3. 实际打开原文核验，搜索摘要不可标已验证；
4. 不出现品牌、公司、产品或 APP 名；
5. 不涉政治、事故、社会负面与敏感国际事件；
6. 对华为用户实用、轻松、有品位，不贩卖焦虑。

财经不做个股/基金推荐、涨跌预测或恐慌；健康不做医疗承诺；体育避开奥运/世界杯；天气只用官方预警和服务提醒角度。

## 工作流

1. 确定素材范围、目标上线日、去重窗口；读取 H（全历史）、R（近期上传）、B（本期/本会话）。
2. 按五方向各找2—3条权威线索，实际打开原文。每条先建新闻原子卡：`栏目槽位｜平台/风格品类｜内容主题｜呈现格式｜具体对象｜核心事实｜来源等级/日期｜确定性｜首图/3种内页｜用户主收益｜主钩子｜风险｜H/R/B`。
3. 先分开“栏目槽位”和“平台/风格品类”：财经、健康可标栏目专属；生活出行按核心对象路由旅行/座驾/插画等；趣味谈资可路由萌宠/旅行/艺术/动漫；科技路由科技。错类时换槽，不强行补齐顺序；标题字数和风格跟随实际品类，旅行/萌宠仍≤7字。财经给决策背景但不提供投资建议，健康给有条件的实用提醒。
4. 写标题前完成概念去重：比对对象、核心事实、画面、用户收益与叙事；同题换词或同概念族第三次使用均淘汰。句式/热词多样性不能替代 H/R/B。
5. 对齐对应品类参考表，内部写`对象锚点｜单一钩子｜标题结构｜副标题兑现方式`。锁定事实、确定性、画面和收益，比较陈述型、疑问型、类比/画面翻译型；不适用者不硬造。只留一个主钩子，副标题给具体证据与收益，最多两层信息。
6. 正文按“事实 → 对普通人的意义 → 谈资/可执行提醒”写一段，并维持来源的确定性。正式锁屏条目必须有能证明题眼的首图和至少3种不同内页画面，否则标`待补画面`。
7. 先过共享12项硬门槛和本栏目六条硬闸，再做100分质量评分。正式条目至少75分，本期优先选85分以上；硬门槛失败不能被分数抵消。

## 输出

每条须有标题、副标题、≤150字正文、已验证来源和以下回执：

```text
栏目槽位 / 平台或风格品类 / 内容主题 / 呈现格式 / 具体对象：
素材范围 / 目标上线日 / 去重窗口：
核心事实 / 来源确定性：
首图证明 / 3种内页画面：
主钩子 / 用户收益：
风格对标：
去重回执：H；R；B；窗口；R 数据覆盖起止；数据截止日；H 最近数据日期/日期不完整；解析异常。
质量总分：X/100；弱项：
```

H/R/B、直接来源、确定性、画面、自然语感或75分门槛任何一项未满足时，写入对应待补清单而非正式一期内容。
