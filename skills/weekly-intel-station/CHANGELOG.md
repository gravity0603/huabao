# Changelog

## [1.3.0] - 2026-09-03

### Changed

- 接入共享治理 v1.1.0 与十品类风格手册：每条先建立新闻原子卡，明确栏目槽位、平台/风格品类、内容主题、呈现格式、对象、事实、来源等级/日期、确定性、首图/3种内页、主钩子、用户收益、风险和 H/R/B。
- 增加五方向语义路由，分开栏目槽位与实际品类；旅行/萌宠条仍执行≤7字，避免为凑固定顺序把财经、生活、趣闻、健康或科技线索错放栏目。
- 同一事实内部比较陈述、疑问、类比/画面翻译结构，不适用时不硬造；副标题最多两层信息且不得复述或新增第二钩子。
- 新增100分质量复核：正式条目至少75分，本期优先选择85分以上候选；共享硬门槛失败不能被高分抵消。
- 回归评测新增确定性升级、标题副标题复述、“不得为凑5条降低质量门槛”和跨品类动态字数场景。

## [1.2.0] - 2026-08-30

### Changed

- 接入共享选题治理契约：用户指定范围覆盖周报默认近7天；目标上线日与至少30天去重窗口独立计算。
- 每条成稿强制月报参考风格对标、H/R/B 跨会话去重回执和数据覆盖状态；近期上传数据不足时降级为草案。
- 标题流程调整为先审语感、对象和兑现，再检查字数，禁止截尾和为凑字生造问句。

本文件记录 `weekly-intel-station` Skill 的可复用规则与输出契约变更。

## [1.1.0] - 2026-08-14

### Changed

- 重排每周固定 5 条内容顺序：财经热点 → 生活出行 → 趣味谈资 → 健康养生 → 科技新知。
- 财经方向扩展为黄金、股市、居民消费政策和消费避坑，并保留不做个股推荐、涨跌预测、投资建议和恐慌渲染的底线。
- 生活出行方向扩展为油费/燃油费、交通新规、出行避坑、出行提醒和官方天气服务信息。
- 趣味谈资方向加入艺术趣闻，覆盖动物、宠物、旅行和艺术。
- 健康养生方向加入体育、饮食和育儿资讯。
- 科技新知方向加入重大奖项等公共科技资讯。
- 明确天气新闻只能采用官方预警和服务提醒角度，不渲染灾害、伤亡或损失。
- 同步更新栏目知识库和项目 Context 规划文件。

## [1.0.0] - 2026-08-13

### Added

- 创建「一周情报站」独立 Skill。
- 建立每周 5 条轻资讯周报工作流和输出契约。
- 固化标题、副标题、正文、来源核验和正面内容红线。
- 创建栏目专属知识库，包含华为安卓用户适配、选题方向、来源标准、措辞风险和第一期样例。
- 创建基础 evals 测试用例。
