# 明星类标题与副标题风格指南

## 依据与边界

依据当前参考表：`明星类标题参考.csv` 123条主标题、`明星.csv` 50条历史选题。样本证明的是短标题节奏和标题—副标题分工，不等同于效果数据；现行规格仍为标题≤10字（优先6—8字）、副标题≤25字。

标题负责对象与一个认知缺口，副标题负责证据、差异或答案方向。第二个卖点应删除或拆题，不能转移进副标题。

## 可选结构

| 结构 | 标题特征 | 副标题写法 |
|---|---|---|
| 特征群像 | 人物类别 + 单一可见特征 | N位 + 共同标准 + 1—2个代表差异 |
| 身份经历 | 公开经历/身份 + 对象 | 经历事实 + 现职业或能力反差 |
| 职业反差 | 既有印象 + 具体技能/动作 | 公开训练、节目或采访证据 + 专业价值 |
| 公开关系 | 同学/搭档/队友 + 关系钩子 | 公开关系证据 + 一处代表差异 |
| 成长训练 | 对象 + 可验证变化 | 时间线 + 训练/职业过程 |
| 单人事件 | 姓名 + 具体职业动作 | 公开场景 + 过程 + 专业价值 |

## 对象与副标题

- 群像标题优先女星、男星、演员、歌手等身份类别；副标题最多点2名代表。
- 单人题只在有近期、公开、积极、可视的职业事实时使用姓名。
- 标题已写姓名，副标题不重复“演员某某”，直接补动作、过程与专业价值。
- 疑问标题必须在副标题给答案方向。
- 副标题最多两层信息，不能同时塞名单、经历、作品、评价和情绪。

## 三结构改写

同一事实内部比较陈述型、疑问型、隐喻/画面翻译型。结构必须真的不同；不适用时跳过并说明，不为凑三版硬造。隐喻只能翻译首图可见细节，问句必须有真实认知缺口。

## 常见问题与修法

| 原问题 | 修法 |
|---|---|
| “某女星气质很高级” | 没有事实或可见题眼时返回“应换题”。 |
| 标题有两个以上卖点 | 只留一个主钩子；其余删除或拆题。 |
| 副标题复述标题 | 改为具体动作、数量、场景、差异或答案方向。 |
| 群像标题堆人名 | 标题换身份类别；副标题最多点2名。 |
| 确定性被升级 | 恢复“可能、个人解读”等限定，或停止改写。 |
| 问句无问号 | 加中文`？`，或改为自然陈述句。 |
| “全网、最、封神” | 无直接来源与范围一律删除。 |

## 风险

不以绯闻、婚变、私人关系、未成年子女、健康、整容、胖瘦、国籍民族等敏感身份制造点击；反差优先职业能力、公开训练和角色塑造。
