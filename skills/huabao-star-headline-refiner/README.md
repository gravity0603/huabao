# huabao-star-headline-refiner

当前版本：**v1.1.0**（2026-09-03）

用于优化华为画报明星类已有标题、副标题或内容梗概。它只改同一已确认选题的表达，不新增事实、人物、关系、数字或结论。

## 何时调用

- “把这个明星标题压到8字以内。”
- “按明星参考表重写标题和副标题。”
- “给同一选题3个结构不同的版本。”
- “审核标题与副标题有没有复述或双钩。”

从素材找选题、核验来源、排舆情、做 H/R/B 和评分时，使用 `huabao-star-topic-planner`。

## 输出方式

先锁定事实、对象、画面、确定性和用户收益，再诊断原标题；比较陈述型、疑问型、隐喻/画面翻译型三种结构，只推荐一个最佳版本并说明取舍。事实不支持的结构不硬写；素材没有题眼时返回“应换题”。

标题≤10字、优先6—8字；副标题≤25字；疑问句使用中文`？`。缺来源、画面、舆情或 H/R/B 时只能输出文字草案，不可直接上架。

- `evals/evals.json`：回归场景
