# 华为画报明星类标题优化

只优化同一个已确认选题的表达，不凭空新增人物、事件、数字、作品、关系或结论。目标不是机械削短，而是对象明确、钩子单一、证据可兑现、读起来顺。

## 启动、路由与边界

先读本 Skill 的`references/style-guide.md`；审核时再读`references/review-checklist.md`。安装后从本 Skill 目录解析`../huabao-content-planner/references/selection-governance.md`及同目录`category-style-playbook.md`；参考表优先读取用户当前指定或项目地图登记的`明星类标题参考.csv`与`明星.csv`。任一外部文件不存在或不可读时，只能使用已提炼的本地风格指南并列明缺失项，不得声称已读取、已对标或已完成上游核验。

演员公开职业、经历、技能和群像归明星；角色动机、剧情、镜头、台词、道具应转影视流程。本 Skill 不发掘素材、不新增事实、不自行宣称已完成来源、舆情或 H/R/B。缺有效上游回执时固定标：`文字优化草案，不可直接上架。`

## 改写流程

1. **锁定五项**：事实核心、对象、首图画面承诺、事实确定性、用户主收益；保留已给作品/节目、事件、数字和时效。任何版本不得改变这些字段。
2. **诊断原标题**：只选最主要问题——泛、长、双钩、无对象、问号错误、情绪过量、确定性升级、标题副标题复述或画面不支持。
3. **确定唯一题眼**：盘点、身份、职业反差、公开关系、成长/训练、职业场景、单人公开事件中只选一个；其他卖点删除或拆题，不能塞进副标题。
4. **生成三结构**：基于同一题眼分别写陈述型、疑问型、隐喻/画面翻译型。三版必须改变信息组织方式，不得只换同义词；事实不支持的结构写“不适用”及原因，不能硬造。
5. **写副标题**：群像用`N位+共同特征+1—2个代表差异`且最多点2名；单人用`动作/过程+专业价值`。最多两层信息；疑问标题给答案方向。
6. **最后压缩**：只删空泛形容、重复身份和无信息词。标题≤10字、优先6—8字；副标题≤25字；疑问句用中文`？`。不得截尾、硬缩或删掉必要的确定性限定。
7. **唯一推荐**：只选一个最佳版本，说明保留了什么、牺牲了什么、适配哪张首图。

若素材没有具体对象、可核事实、可见题眼或阅读收益，直接返回`应换题`，说明缺口并建议回到明星选题 Skill；不再输出吸睛版本。

## 风险底线

不润色绯闻、婚变、隐私、未成年子女、健康、整容、身材羞辱、攻击性比较、未经证实关系或负面舆情选题。不得把“可能、个人解读、传闻”升级为“证实、明确、真相”。纯品牌造型或商业活动不得包装成内容选题。
