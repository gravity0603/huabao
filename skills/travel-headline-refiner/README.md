# travel-headline-refiner

当前版本：**v1.3.1**（2026-09-10）

用于精炼、改写或审核华为画报旅行风光标题。它锁定同一选题的对象、事实、画面、确定性和用户收益，只优化表达，不新增地点、现象、数字或结论。

## 核心能力

- 纯改写已有标题时只优化表达，不新增事实或启动新选题流程。
- 对齐当前旅行参考表的短、具体、真实反常和口语节奏。
- 增加“先说人话，再压7字”的活人感闸门：拒绝平淡说明、翻译腔和热词套壳，修辞必须从景观自然长出来。
- 增加“先显义，再巧”的清晰度闸门：双关和机锋不能替代景观的关键动作、形态或空间关系。
- 比较陈述型、疑问型、隐喻/画面翻译型三种真正不同结构。
- 标题≤7字、副标题≤25字；一题一钩，副标题补证据与答案。
- 只推荐一个最佳版本并说明取舍和适用首图。
- 没有具体题眼时返回“应换题”，不靠夸张词硬救。
- 没有来源、画面或 H/R/B 回执时只输出文字草案，不标主推；找不到可核验来源时如实说明，不伪造链接或核验结果。

新选题、来源核验、画面筛选、H/R/B 和完整评分请使用 `huabao-travel-content-planner`。

- `references/style-guide.md`：风格与确定性规则
