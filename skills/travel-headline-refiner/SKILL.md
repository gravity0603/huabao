# 旅行标题优化

将同一个已确认旅行事实改写为“一个具象对象 + 一个真实反常/旅行利益点”的自然短标题。只改表达，不编造地点、现象、数据、历史、极值或确定性。

## 启动、路由与边界

先读本 Skill 的`references/style-guide.md`。安装后从本 Skill 目录解析`../huabao-content-planner/references/selection-governance.md`及同目录`category-style-playbook.md`；参考表优先读取用户当前指定或项目地图登记的`旅行类标题参考.csv`与`旅行风光.csv`。任一外部文件不存在或不可读时，只能使用已提炼的本地风格指南并列明缺失项，不得声称已读取、已对标或已完成上游核验。

地点、景观、建筑外观、地理现象和旅行生活归旅行；工艺史/审美归艺术，交通工具结构归座驾/交通，纯工程/科学机制归科技。路由不成立时停止旅行改写并指出正确品类。

本 Skill 不发掘新素材，不替代直接来源、首图/内页、版权、H/R/B 和评分。无有效上游回执时固定标：`文字优化草案，不可直接上架。`

## 改写流程

1. **锁定五项**：具体对象/地点、核心事实、首图画面承诺、事实确定性、用户主收益。任何版本不得改变。
2. **诊断原题**：只选主要问题——泛对象、过长、双钩、无认知缺口、空泛情绪、问号错误、确定性升级、标题副标题复述或画面不支持。
3. **确定唯一题眼**：视觉反常、机制揭秘、实用决策、故事谈资或情绪共鸣只选一个主钩子；其他卖点删除或拆题，不能塞进副标题。
4. **比较三结构**：基于同一事实写陈述型、疑问型、隐喻/画面翻译型。三版必须改变信息组织方式，不能只换同义词；事实不支持的结构写“不适用”并说明原因。
5. **先说人话，先显义**：模拟把首图发给朋友时会脱口而出的完整句子，再提炼成≤7字标题。不得从热词清单挑词套对象；拟人、比喻、感官夸张、双关和标点只在景观自然触发时使用。读者必须先看懂对象发生了什么，再感受到双关或机锋；巧词挤掉关键画面时直接淘汰。
6. **写副标题**：具体地点/证据 + 成因、规则或旅行收益，最多两层信息；疑问标题给答案方向，不复述标题。
7. **最后压缩**：标题≤7字、副标题≤25字，疑问句用中文`？`。只删冗词和空泛情绪，不删对象、关键动词、必要条件或确定性限定。
8. **唯一推荐**：执行“朋友转图测试”，复核半秒成像、对象明确、口语节奏、顺口度和转述欲，再选一个最能被首图证明的版本；准确但平淡、有梗但失真、热词套壳和翻译腔都不能推荐。

没有具体对象、可核事实、可见题眼或阅读收益时，返回`应换题`，建议回到旅行选题 Skill；不再用“绝美、震撼、神秘、必去、真相”硬救。

## 确定性与绝对词

- 研究推测用“可能、或与……有关”，不能改成“证实、真相”。
- 理论假设用“假如、理论上”，不能写成现实已发生。
- 地点、尺度、形成原因、首次/唯一/最大均需直接来源、范围和日期。
- 来源只支持背景而不支持题眼时，仍视为题眼未核验。

## 输出

```markdown
### 诊断
- 锁定对象 / 事实 / 确定性 / 画面 / 用户收益：
- 原题主要问题：
- 上游状态：来源；画面；H/R/B

### 三结构候选
| 结构 | 标题 | 字数 | 副标题 | 字数 | 钩子 | 适用首图 |
|---|---|---:|---|---:|---|---|
| 陈述型 | … | … | … | … | … | … |
| 疑问型 / 不适用 | … | … | … | … | … | … |
| 隐喻型 / 不适用 | … | … | … | … | … | … |

### 唯一推荐
- 推荐：
- 取舍：
- 核验状态：文字优化草案，不可直接上架。（上游回执不完整时保留）
```

用户只要标题时可省略副标题列，但仍保留结构、字数、唯一推荐与核验状态。不报100分、不自行标主推；完整评分由旅行选题 Skill 完成。
