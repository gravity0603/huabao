# 旅行标题与副标题风格指南

## 依据与证据边界

当前参考数据：`旅行类标题参考.csv` 61条非空主标题，第三列另有52条独立标题，共113条标题表达；`旅行风光.csv` 50条历史标题。第三列是独立标题池，不能与同一行副标题配对。

61条主标题中90.2%≤7字、47.5%为问句。它们证明短、具体、反常的表达习惯，不证明某句式必然带来更高流量。现行规格：标题≤7字、副标题≤25字。

## 最小成立单元

```text
具体对象/地点 + 常识预期 + 可见反常/旅行利益点 + 原文可兑现答案
```

只有“某地很美”、氛围图或百科背景，没有首图奇点与用户收益时，应判`应换题`。

## 三种结构

| 结构 | 适用条件 | 写法 | 风险 |
|---|---|---|---|
| 陈述型 | 对象和异常本身足够成像 | 对象 + 异常动作/空间关系 | 容易写成平铺百科 |
| 疑问型 | 有真实可回答的认知缺口 | 对象 + 异常/规则 + `？` | 不得为凑问号硬造“也会/为何” |
| 隐喻/画面翻译型 | 首图形状、颜色或状态确实像日常物 | 对象/地点 + 一个有证据的比喻 | 引号和比喻必须由首图证明 |

另有规则/避坑和故事钩子时，也必须归入上述信息结构之一；每题仍只保留一个主钩子。

## 标题与副标题分工

- 标题：对象 + 一个认知缺口。
- 副标题：具体地点/证据 + 成因、规则或用户收益，最多两层信息。
- 疑问标题必须给答案方向；诗性标题必须字面化。
- 副标题不得复读标题，也不得承接第二个卖点。

## 网感闸门

网感不是多加问号或热词，而是用用户熟悉的动作、生活物或口语，把陌生景观的真实反常翻译成一句可转述的话。`地底瀑布群`、`室内落瀑布`这类“地理名词 + 现象”虽准确却平淡，应继续寻找能被首图证明的生活化关系；如规则岩柱可翻译为“铺地砖”，成片倾斜房屋可翻译为“集体歪头”。

- 遮住副标题后，标题仍须在半秒内让人看见具体异常并知道对象。
- 热词、拟人和生活比喻必须逐字映射画面或事实；有梗但失真直接淘汰。
- 同一批同一口语词、拟人动作或句式最多2次，避免批量套壳。
- 准确但平淡与连续反问制造伪悬念同样不合格。

### 活人感与修辞

先模拟真人把图片转给朋友时会说的完整一句话，再压缩成标题。不要先选择“自带、怼到、私藏”等网络词，再把景观塞进去。

- 拟人必须有可见动作或状态；比喻必须外形、颜色或空间关系确实相似。
- 夸张只能放大视觉感受，不能夸大尺度、成因、纪录或确定性。
- 双关的景观字面义与日常语义必须同时自然成立。
- 先显义，再巧：标题应先让读者看懂对象发生了什么，再让人会心。若双关占掉了关键动作、形态或空间关系，即使机灵也淘汰；如`房子，歪得有理`不如`房子偏要斜着站`直接。
- 逗号、引号、感叹号、问号用于口语停顿和语气，不作为装饰；标点计入7字上限。
- 优先级：事实与画面兑现 > 自然活人感 > 新鲜网感 > 修辞花样。

## 用词

优先具体名词与可见动词，如冰川、瀑布、沙漠、盐湖、岩石、桥、塔与开花、倒流、褪色、行走、燃烧。拟人只负责把画面翻译得好懂，不能替代事实。

降低或禁用：绝美、震撼、神秘、必去、超现实照片、最后一个、真相大白。`最、唯一、首次、最大`只有直接来源、范围和日期齐全时才可使用。

## 确定性

| 来源状态 | 可用措辞 | 禁止措辞 |
|---|---|---|
| 已确认 | 已发现、已观测（带范围） | 无范围的全球唯一 |
| 研究推测 | 可能、或与……有关 | 证实、真相就是 |
| 理论假设 | 假如、理论上 | 现实中已经 |
| 待验证 | 待核实、暂不出题 | 任何确定性标题 |

## 30秒自检

- [ ] 对象/地点、事实、确定性、画面和用户收益未被改写。
- [ ] 标题只有一个主钩子，首图能证明最关键的2—4字。
- [ ] 三结构真正不同；不适用者没有硬造。
- [ ] 标题≤7字、副标题≤25字、疑问句用中文`？`。
- [ ] 副标题补证据与答案，不复述、不加第二卖点。
- [ ] 极值、数字、地点和成因有直接来源。
- [ ] 无题眼时已返回“应换题”。
