## 1. 三个本地工作模型

三个模型均有跨品类案例和可执行决策，但尚无资料证明为行业独有。按master-skill三重筛选，它们属于本地工作模型与决策启发式候选，不标成通过全部验证的行业独有心智模型。下面示例仅说明方法，不是新选题或已核验成品。

### M1 首图、标题、正文围绕同一个事实

一句话：先定位一个看得见或能具体讲清的对象和反常，再让标题、副标题、摘要兑现同一看点。

- 依据一：[知识方法04](research/04-canon.md) L1/L2：旅行的可见反常、猫狗的具体动作、影视的角色/剧目锚点，以及内部三种标题切口竞争。
- 依据二：[术语规范06](research/06-glossary.md) G01/G02：平台快照要求图文一致，用户要求四项题卡；AP视觉方法要求不误造现场。
- 复现：旅行的形态/方向反常与猫狗行为问题都可由具体画面承接；影视/明星则由作品、角色或公开造型承接。
- 应用：用普通话写“具体对象是什么、读者会意外什么、原文证明什么”。内部比较直观反差、生活场景错位、具体用途/能力三种切口，选一个。三种都平淡就换对象或事实，不加“震撼”补救。
- 局限：知识题不一定能一张照片直接证明机制，画面可展示对象、解释图展示机制；本助手核对象与标题事实，图片是否合适由用户人工复核；不能声称未做的图片审核已通过。比喻不能将形态相似改写成真实事件。

### M2 新题看事实增量，而非措辞变化

一句话：对象、核心事实/机制和读者收益/视觉切口共同决定概念差异，改标题不增加新题价值。

- 依据一：[工作流03](research/03-workflows.md)：H/R/B语义比较、上传单元格多题和历史文件结构的读取边界。
- 依据二：[信息源05](research/05-sources.md)与[知识方法04](research/04-canon.md) L1/L2：账号提供对象线索；品类参考和旧高曝光题只借表达机制，不复用旧概念。
- 复现：相同景观机制换地点，以及相同猫狗行为问题换说法，均可能仍属同概念族；同作品同桥段换话术同理。
- 应用：登记“对象＋核心事实/机制＋收益/视觉切口”，先与历史、近期、当前批次比较，再决定原文核验投入；核验后再次比对回修的实际事实。重做须有新机制、新事件或实质解释增量，并说明差异。
- 局限：同对象并不必然重复，同机制也不能机械封杀全部对象；需比较实际问题和内容增量。记录覆盖不足时只能说明已读范围与待补R复核，不能判全面无重复。

### M3 吸引力、平台适配和发布条件分别判断

一句话：历史曝光帮助选择待测试方向，平台案例帮助理解供给偏好，实际发布还需要事实、图片、权利和审核证据。

- 依据一：[知识方法04](research/04-canon.md) L4：N/P复盘区分月度新标题集、观察截止与月报入选；不同品类同时出现高曝光与案例入选不一致的情形。
- 依据二：[术语规范06](research/06-glossary.md)：平台质量要求、历史审核反馈、图片许可及实际审核结果是不同证据链。
- 复现：猫狗动作问题有可测试的读者价值，艺术/插画的案例入选还可能反映画面与供给多样性；不能互相替代。
- 应用：策略任务按“同口径数据→解释及不确定性→小批试验方向”交付。选题任务先守事实与题材底线，再比较吸睛和可写程度；不设评分自动放行。
- 局限：本轮没有重算原表或做因果试验，历史表现只是线索；月报无图组ID时同名不证明同组。没有点击与对应曝光分母时不计算CTR。

## 2. 八条决策规则

| 场景 | 具体决策 | 示例及边界 |
|---|---|---|
| 用户已有素材/链接 | 先读本次输入与素材库，再补检索；有时间字段优先最新，无日期则查入口最新正文 | 账号主页可发现下一篇正文，但不能支撑文章中的事实。CSV尾行不等于最新 |
| 候选只有类别或形容词 | 换成具体对象及单一事实钩子；三个切口仍平淡则换题 | “奇特建筑”是范围，“某建筑的真实异常结构”才是可研究的对象；不直接照抄示例成标题 |
| AI或转载给出惊人断言 | 定位原始资料并核正文；没有可靠原文则淘汰或单列待验证 | 多站复制同一说法不是多方证据；AI给出URL仍要实际打开 |
| 标题超出证据范围 | 改标题结论，并在副标题补关键条件；不能靠正文末尾纠错 | 猫异常行为不可直接定性为情绪；实验演示不称已量产，关联不写成原因 |
| 同概念已做 | 优先换对象与事实；有实质新事件才说明增量重做 | 换城市、品种、人名或问句不自动构成新概念；同对象的新事实可另评 |
| 用户自行复核图片 | 只核真实对象和标题事实，不下载、逐图检查或把图片检查列为交付门槛 | 用户明确要求识别某图时限于该对象与标题一致性，不扩成整组审查 |
| 用户只要求改稿 | 依据所给事实与相关品类参考直接改；只核新增事实 | 不展开无关全库与多轮图片下载；指定字数、段数和段长优先 |
| 数据/审核结果看起来很好 | 查口径与实际完成范围，再决定用途 | N/P不等于库存/CTR；高P、月报入选、机械通过均不代表已授权或平台通过 |

## 3. 工具选择与任务路径

工具按任务所需能力选择，不声明“80%从业者必用”，不推荐未核实新付费服务。详情见[工具地图02](research/02-tools.md)。

- **本地输入与风格**：CSV解析；需要时读取工作簿、月报或SOP。旅行双“标题”列保留列位置；上传一格多题拆分且保留日期。先用本次路径，再定位默认路径，快照注明日期。
- **对象与原文**：可用搜索/浏览器；对象不足可用当前一种AI辅助。入选题打开正文记录来源和关键事实，动态/登录页面按实际工具能力读取。
- **图片分工**：用户人工复核图片适用性、规格、构图与权利；本助手核真实对象与标题事实。用户单独询问图源/规范/授权时仅回答该问题，不默认扩成逐图审核。
- **机械校验与复盘**：结构化JSON可选字段/长度校验，无JSON不额外造文件；数据任务才读对应指标和运行统计。脚本不证明事实、版权、舆情、语义去重或标题审美。

### 最小完整路径

新题：读取相关输入和风格→筛具体对象/真实钩子并初步去重→内部竞争标题→核入选原文→回修事实与标题、完成范围内概念比较→检查题材风险及配图可行性→四项题卡与具体缺口。

改稿：用户事实/来源及相关品类样本→对象、单一钩子和指定结构→不同表达方案→限长与事实兑现→直接成品。

对象/审核问答：已选题与事实依据→核真实对象与标题事实一致→按用户提出的具体规范或审核问题回答；图片由用户人工复核，平台通过只依据实际结果，不默认接管图片制作与审核。

复盘：定义标题集、粒度、观察截止、指标及去重口径→检查标签错配和同名问题→同口径比较→写假设、限制与可验证调整。不从不同累计观察期反推因果。

### 熟练工作时如何省成本

仅加载当前品类和模式；先淘汰重复/平淡对象，只核入选题；已读原文足够支撑时不重复打开，无冲突不扩大查询。普通找题直接用已核本地平台摘要，遇更新请求、新反馈、已知变动或实际提审需要最新版再刷新。近期工作变化是2026-10-13用户反馈后确立的分阶段流程，不伪称全行业AI工具趋势。

## 4. 表达与品类决策

外部成品：对象明确、细节具体、真实反差、口语顺畅；先显义再巧，句式有变化。标题制造一个可兑现的好奇点，副标题补对象/条件，摘要解释原文证据及必要边界。内部记录用精确日期、主张与证据，不把大量流程字段推给用户。

| 品类 | 先找的事实锚点 | 避免的替代物 |
|---|---|---|
| 旅行 | 景物/建筑、真实形态或动作反常、应季体验与可核地点 | 泛氛围词、错季、比喻写成事件 |
| 萌宠 | 猫狗具体行为、照护问题、人宠互动；最多含熊猫 | 模糊“它”、花色决定性格、表演或危险动作作趣味 |
| 明星 | 公开造型、才艺、作品、职业动作与真实趣事 | 绯闻、负面误导、拉踩、品牌种草；合集按用户当前要求核案例，单人题不硬凑人 |
| 影视/动漫 | 具体作品、角色/桥段、共同主题；熟悉IP的可核陌生细节 | 演员现实关系替代剧情、待播写热播、旧新闻装近期 |
| 科技/科普 | 可见现象、装置、研究发现及阶段、机制和条件 | 想象图当实拍、相关写因果、候选写确定发现 |
| 座驾/体育 | 部件、规则、真实工艺、运动事实及安全条件 | 性能广告、危险建议、忽略型号/赛季/地区 |
| 历史/艺术/生活 | 器物、作品、真实人物或可解释生活场景 | 无据故事、作品名替题眼、争议说法写定论 |

用户未指定时，普通题卡为标题、副标题、单段含论据摘要、`[来源名·实际文章标题](https://...)`。摘要以事实复杂度决定长度，约100–180字仅为可调整建议；用户指定结构与字数优先。旅行/萌宠标题≤7字符，其余≤10，副标题≤25；标点、空格、数字、英文字母计数，疑问句带问号。全流程排除日本相关元素，归因为用户工作偏好。

## 5. 五项质量基准与八种反模式

质量基准：

1. 对象、单一看点和内容增量明确，标题读得顺且正文能直接回答。
2. 每题有实际打开的可靠核心原文，关键事实与来源对应，不造日期、标题、URL或全网共识。
3. 概念比较覆盖范围可复核，批内机制和句式有差异，覆盖不足准确声明。
4. 真实对象与标题事实一致，品类风险和时效已按所做范围记录；不擅自代理用户图片审核。
5. 数量、四项字段、字符、问号及用户指定字数/段数满足；数据/策略明确依据、判断与限制。

反模式：百科摘要压标题；全批同一种问句；用问号/引号保护夸大断言；AI回答当证据；首页/搜索页装文章；字面去重替概念比较；每个草案逐图下载挤占找题；高分/高P或脚本通过自动称可上架。

### 核验状态怎样记录

内部记录事实与去重覆盖，平台结果仅在用户提供/要求时记实际证据。图片人工复核不由本助手代报；不把任何状态笼统称全通过。

- 核心事实未证：待验证线索，不能混入已核实题卡凑数。
- 事实有原文：选题草案；默认无需重复图片核验说明，也不为图片待审阻断交付。
- 近期覆盖缺口：在对应题/批注明待补R复核及起止范围。
- 用户问制作/权利：只据实际信息回答，不能代报人工图片复核完成。
- 平台通过：只有实际平台结果能支持，仍按用户明确发布范围行动；本Skill不自动发布。

## 6. 方法来源的关系与真实分歧

没有足够证据建立锁屏策划的公认学派与奠基人。保留三个可追溯的方法视角：用户本地的视觉钩子与标题竞争；Reuters/AP的归因、核验与视觉真实性；SMC的科学证据范围与研究成熟度。它们不是人物人格子技能，也不互相替代。

要解决的张力：短标题与必要条件之间，用准确结论＋副标题条件解决；找题速度与核验成本之间，先筛对象再核入选题、核心对象身份与事实争议提前核；历史曝光与平台案例之间，分指标比较。用户允许AI创作，不继承AP内部禁写政策；历史单案品牌/文字反馈不泛化为永久平台条款。

## 7. 七个研究维度：按任务取用

这些是遇到新问题的查询入口，不是每次都必跑七项。纯改稿只读相关事实、品类参考与限长；新题才查素材、原文和概念；制作/复盘增加对应检查。

| 维度 | 具体动作 | 形成什么 |
|---|---|---|
| 输入与边界 | 读取本次素材、最新入口和品类参考；识别数量、时间/季节、地区、模式 | 本批范围与所读依据 |
| 对象与题眼 | 用对象/作品/作者/地点组合检索；比较至少三种不同标题切口 | 一句话事实钩子与最终标题 |
| 原文与主张 | 打开正文，核日期、数据、机制、研究阶段和条件；冲突时追原始材料 | 来源名、原标题、URL、读取日、支持事实与限制 |
| 概念差异 | 定位实际H/R文件，按表结构抽取多标题；对照本批与当前对话 | 指纹、差异、重复处理与覆盖缺口 |
| 真实对象一致性 | 核对象身份、地点/作品、动作机制与标题；用户提供图并要求识别时仅核该对象 | 对象与标题的事实对应，图片适用性归用户人工复核 |
| 品类与审核风险 | 核人物舆情/作品播出状态/技术条件/安全边界等相关风险；按本地规范筛方向 | 保留、换题或具体待审问题 |
| 反馈与数据口径 | 复盘时核标题集、ID粒度、截止日和指标；区分月报案例与曝光 | 同口径结论、可测试假设和限制 |

## 8. 诚实边界与维护

1. 17个公开URL属于有限方法样本；三个模型为用户工作适配，不称独有行业模型、全景共识或人物排名。
2. 华为规范本轮未在线复核，依据本地2026-10-13读取快照；实际提审需最新版时针对核查。规范、图片规格、竞品范围、人物动态与工具入口会变。
3. 未重算原工作簿、重读全部月报、逐条做本轮新题去重或核图片授权；已读复盘只支持方法与历史假设。
4. 影视/明星/体育外部方法覆盖较弱，执行具体任务需补其事实来源，不能靠通用方法自动判热点、舆情或权利。
5. 公开机构材料也有组织视角与选择偏差，不代替用户实务反馈或平台实际结果。用户新反馈优先调整对应规则，不据一次失败扩张全部流程。
6. 可分发包保留摘要与来源，私有CSV、精确曝光数、月报全文和聊天长文不公开；工作记录放用户工作目录。无需上传整库给外部AI。
7. 触发说明、引用、模板和规则要自包含；研究中路径为追溯记录，构建时将必要规则摘要随包提供，不要求必须安装旧策划Skill才能用。

构建需检查自包含引用、运行新脚本与独立行为测试；实际验证与安装状态以meta.json和交付结果为准。保留已有专项Skill，不删除、不改写其入口。没有远端提交/发布授权时，不宣称远端同步完成。
