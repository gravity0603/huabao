# 工作流研究：从素材线索到可继续生产的题卡

研究日期：2026-10-14。Wave 3，已读取01、02、04、05、06轨研究笔记及本地SOP正文。以下是用户流程与公开编辑方法的对照研究，尚未进入最终操作系统提炼。机构方法不等于平台条款。

## 本地SOP与当前偏好的衔接

原始依据：`D:/yiyouliao working/工作内容/每周数据/数据库/华为画报sop.docx`。已用DOCX XML抽取全文正文，未查看文中案例图片。正文四步为：梳理月报优秀案例、定位素材灵感、筛选真实素材、编辑撰写。旧例子只作方法分析，不再推荐旧题。

有用机制：从案例标题检索到素材，遇到译名搜不到则组合作者、作品、对象和形态关键词；找到原作者及真实作品再写。需调整处：SOP末尾的AI再次核对只能帮助找核查点，不能算事实实证。04轨Reuters/AP支持原始归因、核验与图像身份检查；SMC支持研究阶段和条件检查。

新版本地 `huabao-topic-studio` 保留素材先读、对象发现、三种标题切口竞争、入选题原文核实、四项交付，且普通草案不逐图下载、不每批重开平台规范。制作核验在用户选定后进行。旧治理中的正式制作检查保留到对应阶段，不前移为普通找题门槛。

## 三类实际任务路径

| 任务 | 读取与行动 | 最小交付及状态 |
|---|---|---|
| 批量新选题 | 本次素材→品类参考→历史与近期记录→小批对象/真实钩子→内部竞争标题→打开入选原文→语义去重→风险与配图可行性 | 标题、副标题、单段论据摘要、真实原文链接；图片精查/授权后置说明；具体证据或R覆盖缺口定位到题目 |
| 已有标题或文案修改 | 用户事实及指定参考→对象与单一钩子→不同结构改稿→限长与事实兑现 | 直接给成品；不为纯改稿展开无关全库研究；新增事实需要原文证据，用户未提供时不补造 |
| 选定题制作、审核或复盘 | 制作：逐图对象/地点/真实性/规格/安全区/授权与页面一致。复盘：定义样本、粒度、指标、观察期，核验真实工作簿 | 制作给检查结果和具体缺项，审核通过须有平台结果；复盘按数据依据→判断→结论，未实测不报完成 |

## 读取和去重的易错点

- 本轮已定位的历史文件是 `zcy华为画报选题-已做选题标题.csv`；旧默认“张朝阳已做”路径不能假定存在。表头与内容混杂，需按真实结构提取，不能把排班说明当选题。
- 历史CSV1620条、上传CSV530条是记录数，不是标题数。上传表“图组名称”单元格含多个题，须识别列表分隔并保留日期，不能一行当一个概念。尚未做完整标题抽取与本轮新题去重。
- 素材库无采集日期字段。先读用户本次新增/指定入口，再查看账号最新正文；不要把CSV尾行或URL数字当作最新日期。
- 旅行参考存在两个同名“标题”列，读取时保留列位置，不能让字典覆盖第二列。已完成去重必须说明实际文件、日期覆盖与语义比较范围。
- H/R/B在此指历史、近期与本批去重，不是工作表列。对象＋核心事实/机制＋视觉切口/收益相同视为概念重复，换标题不构成新题。

## 失败时的具体走法

| 情况 | 决策 |
|---|---|
| 三个标题都只是百科标签 | 换对象或事实切口，少用形容词和标点补救 |
| 原文打不开或只见摘要 | 换可靠原文；仍缺证据则待验证或淘汰，不能编文章名/URL |
| 标题依赖照片真伪或错认地点 | 针对关键图核验；未解决前不作为可信题眼 |
| 同一事实多站转载 | 追最初来源；不能把转载数量当独立佐证 |
| 核验源支持范围比标题窄 | 缩小结论，副标题补关键条件；不能在文末补免责声明来修正错误标题 |
| 近期上传缺少连续日期 | 写具体覆盖缺口与待补R复核，继续交付真实草案 |
| 历史高曝光涉及当前禁用对象或超字数 | 只学机制，不能复制标题或照做题材 |
| 权利页面有一般许可，但具体图含第三方署名 | 逐图检查权利人和用途；一般政策不代表该图已获许可 |
