# 明星类选题方法论

## 依据与适用范围

本方法论归纳自用户提供的《明星类标题参考.csv》（123条非空主标题）和《明星.csv》（50条带月份的历史选题）。参考表证明的是表达方式，不是效果数据；标题高度集中在7字附近，历史副标题常超过现行规格。本 Skill 一律执行标题≤10字、副标题≤25字。

适用华为画报“明星”品类中的演员、歌手、爱豆及公开职业动态。它不是娱乐新闻转载器：优先轻科普、公开职业经历、作品/综艺互动、视觉题眼和成长关系。

## 一句话策略

**具体对象 + 可验证的反差、悬念或承诺。**

标题要让读者瞬间识别对象，同时获得一个值得点击验证的点。群像优先用女星、男星、演员、歌手等身份类别；单人只在有近期、公开、积极、可视的职业动作或事件时使用姓名，不局限于热点，但必须有直接来源、画面和舆情回执。

## 高优先级选题方向

| 方向 | 可用事实锚点 | 标题结构示例 |
|---|---|---|
| 特征标签盘点 | 明确外形、声线、体态、技能、童年照 | `盘点桃花眼男神`、`冷脸萌男星` |
| 归类身份 | 年代、地域、职业训练、赛道、学校 | `99年当红小花`、`学医的男歌手` |
| 职业反差 | 既有印象与公开技能/经历反差 | `甜妹的低音嗓`、`女星的运动底牌` |
| 公开关系 | 可验证的同学、搭档、队友 | `他们曾是队友？`、`同窗演员再合作` |
| 隐藏经历 | 公开履历、训练、转型、专业背景 | `当过兵的男演员`、`学医的男歌手` |
| 成长训练 | 公开训练、考学、转型和职业变化 | `演员训练前后`、`童星的职业转身` |
| 单人事件 | 明确作品、节目、公开训练或采访 | `演员咬手臂入戏`（须来源、画面、舆情齐全） |

纯造型/穿搭只能在有明确视觉题眼、作品场景或反差时使用；“某某感”“氛围感”“高级感”这类抽象形容不得单独成题。

## 标题公式与副标题兑现

### A. 盘点承诺型

- 标题：`盘点/大赏/图鉴/大揭秘/大公开 + 具体对象或标签`
- 副标题：`N位 + 明确筛选标准 + 1—2个代表差异`，最多两层信息、最多点2名
- 适合：特征、身份、成长、视觉题眼。

### B. 归类标签型

- 标题：`年代/地域/圈子/具象标签 + 对象身份`
- 副标题：`N位对象 + 共同归类依据 + 差异点`
- 避免：只有“高颜值”“气质好”等无法成像的标签。

### C. 反差型

- 标题：`既有印象 + 也/却/竟然/不 + 反差`，或直接使用可识别反差标签。
- 副标题：先写反差事实，再点名或补充场景。
- 反差必须能在原文、访谈、作品、视频或公开履历中验证。

### D. 关系/秘密型

- 标题：`他们 + 关系 + ？`、`对象 + 大揭秘`。
- 副标题：解释关系成立的事实，最具意外感的例子放后面。
- 只能写公开且可验证关系，不能借绯闻或私人关系做谜面。

### E. 热点事件型

- 标题：`姓名 + 明确动作/事件`。
- 副标题：作品/节目/视频场景 + 关键细节；不夸大网友反馈。
- 仅时效明确且已经打开源文时采用，热点失效后不作为常驻题。

## 语言节奏

- 直观直白优先于文字双关；一秒读懂优先于文学化表达。
- 常用但需事实支撑的推进词：`盘点、原来、没想到、竟然、藏不住、上榜、反差`。
- `？`只用于真正的问题或悬念；`！`只用于可信的强反差，避免滥用。
- 副标题用事实兑现，不堆“绝美、震撼、封神、全网沸腾”等空泛夸张。

## 评分

### P 潜力 A / 10

对象识别、点击钩子、近期同类表现、标题直觉、时令/分发适配，各 0—2 分。A≥7 才进入分发候选。

### 月报潜力 B / 10

一秒画面、事实信息增量、图像/版权可用性、新鲜差异、月报/栏目适配，各 0—2 分。B≥8 才进入月报候选。

A/B 是业务评分，不能替代共享治理的100分质量评分和硬门槛。只有硬门槛通过、质量总分≥85、A≥7 且 B≥8，才可主推；其余按共享契约与专项规则降级。

## 红线与降级

- 无实际打开的直接来源或确定性不明：`待验证`，不能上架。
- 无首图证明或不足3种内页：`待补画面`，不能主推。
- 无素材库/已做标题/近期已出选题：`去重未完成`，不能宣称不重复。
- 未逐人完成近期负面舆情检索：`待排舆情`；严重或持续负面争议直接放弃。
- 绯闻、婚变、隐私、未成年子女、健康、整容、身材羞辱、未经证实关系或非必要敏感身份：直接放弃。
- 事实、画面或用户收益不足：输出`应换题`，不要用标题公式补出不存在的卖点。
