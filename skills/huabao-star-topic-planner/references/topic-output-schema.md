# 明星选题输出模板

## 正式候选

只有直接来源、画面、舆情、H/R/B 与硬门槛全部通过时使用：

```markdown
### 选题 N：标题（X字）

- 状态：主推 / 可用
- 子方向：
- 素材范围 / 目标上线日 / 去重窗口：
- 核心事实：
- 来源确定性：已确认 / 研究推测 / 理论假设 / 个人解读
- 原文证据：[已验证] [来源名·文章标题](https://...)；等级；发布日期；打开时间
- 首图证明：画面哪处直接证明题眼
- 内页画面：1）…；2）…；3）…
- 主钩子 / 用户收益：
- 风格对标：对象/身份 | 单一钩子 | 标题结构 | 副标题兑现方式
- 概念指纹：人物/群体 | 核心事实 | 视觉题眼 | 用户收益 | 叙事角度
- 去重回执：H；R；B；窗口；R 数据覆盖起止；数据截止日；H 最近数据日期/日期不完整；解析异常
- 舆情回执：检索时间；范围；关键词；来源；结论与处置
- 质量总分：X/100；弱项：
- P 潜力：A/10；月报潜力：B/10

**标题**：
**副标题**：（X字）
**落地页文案**：（150—300字，维持同一确定性）

**风险自检**
- [x] 来源直接支持标题，标题与副标题无错配、复述或双钩
- [x] 标题≤10字、副标题≤25字、问句标点正确
- [x] 首图可证明题眼，且至少有3种不同内页画面
- [x] 已完成逐人近期负面舆情检索
- [x] 无绯闻、隐私、未成年子女、健康、整容、身材羞辱或敏感身份风险
- [x] H/R/B 概念去重完成，确定性与版权/品牌风险合规
```

## 修改后复审清单

质量总分65—74但来源、画面、舆情和 H/R/B 等硬门槛已通过的内容，只能放在此清单，不得套正式候选模板：

```markdown
### 修改后复审：标题草案
- 状态：修改后复审
- 质量总分：X/100；主要弱项：
- 必改动作：
- 复审条件：
```

## 待补池

```markdown
### 素材池：标题草案（不可上架）

- 状态：待验证 / 待补画面 / 待排舆情 / 去重未完成 / 应换题
- 已知事实与确定性：
- 当前缺口：
- 可保留方向：
- 下一步：
```

没有完整原子候选卡时不报100分，不勾选未实际执行的检查。不能因为用户只要求“出标题”就把待补内容伪装成可上架成品。

## 审核结论

按`主推 / 可用 / 修改后复审 / 待验证 / 待补画面 / 待排舆情 / 去重未完成 / 应换题 / 淘汰`分类，每条先写最关键原因，再列实际证据。
