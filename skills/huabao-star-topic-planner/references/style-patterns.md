# 明星标题与副标题风格模式

这些模式只用于理解结构和节奏，不用于照抄案例。群像以身份类别承载共同点；单人只在有近期、公开、积极、可视的职业事实时使用姓名。

| 结构 | 标题特征 | 副标题兑现方式 | 适用边界 |
|---|---|---|---|
| 特征群像 | `人物类别 + 单一可见特征` | N位 + 共同标准 + 1—2个代表差异 | 特征可成像，最多点2名 |
| 身份经历 | `公开经历/背景 + 对象` | 经历事实 + 现职业/能力反差 | 履历有直接来源 |
| 职业反差 | `既有印象 + 具体能力/动作` | 公开训练、节目或采访证据 + 专业价值 | 不用身体或私人关系造反差 |
| 公开关系 | `同学/搭档/队友 + 关系钩子` | 关系证据 + 一处代表差异 | 只做公开职业关系，不碰绯闻/亲属隐私 |
| 成长/训练 | `对象 + 可验证前后变化` | 时间线 + 训练/职业过程 | 不评价胖瘦、整容、健康 |
| 职业场景 | `可见单品/动作 + 职业语境` | 作品、舞台、采访或训练中的具体作用 | 不做品牌软广或纯氛围词 |
| 单人事件 | `姓名 + 具体职业动作` | 公开场景 + 过程 + 专业价值 | 来源、时效、舆情、画面齐全 |

## 副标题合同

- 群像：`N位 + 共同特征 + 1—2个代表差异`，最多两层信息、最多2个人名。
- 单人：`动作/过程 + 专业价值`；标题已写姓名时不再重复身份。
- 疑问标题：副标题必须给答案方向。
- 第二个卖点应删除或拆题，不能转移进副标题。

## 自检

1. 标题能否一眼识别对象与唯一钩子？
2. 副标题是否提供证据、差异或收益，而非复述或新增钩子？
3. 反差是否来自职业事实，不是身体评价、隐私或主观贬损？
4. 确定性是否和来源一致？
5. 首图能否证明题眼，内页是否至少3种不同画面？
6. 是否可能与既有“同对象+同事实+同画面+同收益+同叙事”重复？
