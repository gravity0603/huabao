# huabao-star-topic-planner

当前版本：**v1.1.0**（2026-09-03）

用于把可验证明星素材策划成华为画报锁屏新选题，处理原子候选卡、直接来源与确定性、首图/内页画面、近期负面舆情、H/R/B 概念去重、标题/副标题、落地页及双层评分。

## 何时调用

- “从这些链接出5个女明星选题。”
- “这个综艺热点适合做华为画报明星选题吗？”
- “审核这批明星候选题的来源、舆情、去重和标题。”

已有标题或内容只需优化措辞时，使用 `huabao-star-headline-refiner`。角色动机、剧情、镜头或道具应转影视流程。

## 核心边界

- 群像用身份类别+单一共同点；单人只做近期、公开、积极、可视的职业动作/事件。
- 每位入选艺人都要有近期负面舆情检索回执；未检索只能待补。
- 标题≤10字、优先6—8字；副标题≤25字；一题一钩。
- 正式主推须同时通过12项硬门槛、质量总分≥85、P≥7、月报≥8及 H/R/B。
- 无来源、画面、舆情或去重材料时如实降级；无题眼返回“应换题”。
