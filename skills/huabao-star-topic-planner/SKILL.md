# 华为画报明星类选题策划

把可验证的明星素材转成适合华为画报锁屏的**新选题**。顺序不可倒置：公开事实与画面 → 近期舆情排查 → H/R/B 去重 → 月报参考风格 → 标题对 → 硬门槛与评分。不要从“女星/男星 + 泛形容词”反推空题。

## 启动、路由与参考

依次读取：

1. 安装后从本 Skill 目录解析`../huabao-content-planner/references/selection-governance.md`；
2. 同目录`category-style-playbook.md`的“明星”章节；
3. `references/star-methodology.md`、`references/style-patterns.md`、`references/topic-output-schema.md`；
4. 用户当前素材库、H 已做表、R 上传表、B 当前批次、周数据与月报；
5. `D:\yiyouliao working\选题参考\明星类标题参考.csv` 与 `明星.csv`。

演员的公开职业、经历、技能、训练、造型与群像归明星；角色动机、剧情、镜头、台词、道具归影视。素材核心是角色时转通用 Skill 的影视流程。

参考表只提取“对象/身份 + 单一可验证钩子 + 事实兑现”的结构。先过滤重复、负面、身体评价、过时热点、品类错配和无法核验样例；不得照抄标题、名单或结论。

## 必经工作流

### 1. 建立原子候选卡

确定数量、素材范围、目标上线日和至少30天去重窗口。每篇原文只拆一个候选，并按共享契约记录：

```text
明星对象/群体｜核心事实｜来源等级/日期｜确定性｜首图证明｜3种内页画面｜用户主收益｜主钩子｜风险｜H/R/B
```

没有具体对象、可核事实、可见题眼或阅读收益时，返回`应换题`；没有直接来源、首图或足够内页时进入相应待补池，不能用标题公式补强。

### 2. 核验来源、确定性与画面

实际打开直接来源，核对人物、时间、作品/节目、动作、数字与公开语境。标题、副标题和落地页维持同一确定性；“可能、据研究/采访、个人解读”不得升级成“证实、明确、真相”。首图必须直接证明职业动作、可见特征或公开场景，氛围照不能证明技能；月报级候选至少有3种不同内页画面。

### 3. 逐人排查近期负面舆情

对最终会出现的每位艺人执行近期检索。用户指定范围优先；默认覆盖目标上线日前30天，并补查当前仍在发酵的公开争议。记录检索时间、范围、关键词、来源和结论：

- 未检索：`待排舆情`，不可上架；
- 命中未经证实传闻：不用传闻成题，并扩大核验；
- 命中严重或持续负面争议：放弃候选；
- 群像中任一人物风险不清：移除该人物并重新核验群像承诺。

禁止绯闻、婚变、隐私、未成年子女、健康、整容、身材羞辱、攻击性比较和非必要敏感身份信息。

### 4. 完成 H/R/B 概念去重

用`人物/群体｜核心事实｜视觉题眼｜用户收益｜叙事角度`比对 H、R、B。标题不同但同人物同事实、同画面同叙事，或同概念族第三次使用，仍算重复。R 未覆盖窗口只能标`去重未完成`。

### 5. 对齐明星风格并写标题对

内部建立：`对象/身份｜单一钩子｜标题结构｜副标题兑现方式`。锁定同一事实、画面、确定性与收益，比较陈述型、疑问型、隐喻/画面翻译型三种结构；不适用者明确跳过，不硬造问句或比喻。

- 群像标题：人物类别 + 一个可见特征/经历；
- 单人标题：姓名 + 近期、公开、积极、可视的职业动作/事件；
- 群像副标题：N位 + 共同特征 + 1—2个代表差异，最多点2名；
- 单人副标题：具体动作/过程 + 专业价值，不重复标题身份。

一题只保留一个主钩子；其他卖点删除或拆题，不能塞进副标题。标题≤10字、优先6—8字；副标题≤25字；疑问句用中文`？`。

### 6. 硬门槛与双层评分

先过共享契约12项硬门槛，再给100分质量评分；高分不能抵消来源、画面、舆情或 H/R/B 失败。随后保留业务评分：P 潜力 A/10、月报潜力 B/10。

只有硬门槛通过、质量总分≥85、A≥7、B≥8、H/R/B 全通过且 R 覆盖窗口，才能标`主推`。总分75—84为`可用`，65—74为`修改后复审`，低于65或命中红线为`淘汰`。

## 输出

严格使用 `references/topic-output-schema.md`。待补来源、画面、舆情或去重的内容必须放入对应待补池；不得套正式候选格式，不得伪造已验证、无负面或不重复结论。
