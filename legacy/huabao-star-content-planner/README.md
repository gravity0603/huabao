# 华为画报明星选题策划

[![Version](https://img.shields.io/badge/version-v1.0.0-2f6f6d.svg)](CHANGELOG.md)

> 面向华为杂志锁屏明星类内容的策划与审核 Skill：从可验证公开素材出发，完成题眼筛选、概念级去重、标题副标题、来源核验、风险审查与出街前自检。

当前版本：**v1.0.0**（2026-08-24）

## 适用范围

- 明星公开动态、成长童年、可见特征、正向反差与图鉴大赏
- 童年照、侧脸、剪影、撞脸等可完整揭晓的互动辨认内容
- 短剧演员盘点与公开技能、经历类选题
- 明星选题的来源、去重、红线和画面可行性审核

有具体剧目、角色或剧情细节时应使用影视策划流程；八卦绯闻、未官宣信息、负面舆情、品牌商务内容不属于本 Skill 的处理范围。

## 核心方法

优秀明星选题遵循“熟悉对象 + 陌生但可证实的细节”。标题优先使用 7-9 字的“对象 + 特征/反差/关系/成长钩子”，副标题再补充代表人物、数量、场景和事实兑现。

重点方向：

1. 特征标签盘点
2. 成长童年对照
3. 正向反差
4. 可解释的互动辨认
5. 图鉴/大赏与已官宣的当期公开动态

每条候选必须通过来源核验、概念去重、题眼、画面、字数和红线检查后才能进入成品池。

## 质量底线

- 标题优先 7-9 字，硬上限 10 字；副标题约 20 字，硬上限 25 字。
- 每个成品选题必须附实际打开、可访问的 `https://` 信息源。
- 先按“人物范围 | 共性事实 | 画面题眼 | 叙事角度”做概念级去重，再写标题。
- 不使用未核验履历、绯闻、负面舆情、拉踩、品牌商务或贬损性标签。
- 互动内容必须有完整答案和可解释的信息增量。

## 维护
