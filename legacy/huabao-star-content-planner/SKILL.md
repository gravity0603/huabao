# 华为画报明星类选题策划

## 目标与边界

将可核验的明星公开素材转成适合华为杂志锁屏的明星选题。成品的点击动机来自“熟悉对象 + 陌生但可证实的细节”，不是靠人名、空泛氛围词或八卦刺激。

适用：艺人公开动态、成长童年、可见特征、公开技能/经历、正向反差、造型图鉴、可参与的辨认互动、短剧演员盘点。

不适用或须路由：

- 有具体剧目、角色、剧情细节时，归影视类；不要把女星角色亮点误做成明星类。
- 未官宣恋情、婚育传闻、争议、病痛卖惨、法制风险、拉踩比较，直接放弃。
- 商务代言、品牌活动、产品露出，直接放弃。
- 没有清晰人物图、题眼或可验证事实时，停在素材池，不硬写标题。

## 案例归纳出的策略

两份优秀案例表共同呈现出一个分层结构：

1. **标题先给对象和钩子**：通常 7-9 字，标题只承担“一眼知道在看什么”和“为什么要点开”。例如“甜妹的低音嗓”“男星的花式外号”“他们曾是队友？”。
2. **副标题负责兑现**：补入代表人物、数量、场景、反差和结果。例如“盘点 5 位……”“有人……，最后一位……”。标题不堆人名，副标题可以用 2-4 位代表人物证明不是空话。
3. **盘点必须有筛选标准**：不是“明星合集”，而是同一童年阶段、同一种脸部特征、同一经历、同一技能、同一可比较造型。
4. **反差应具体、正向、可见**：甜脸配低音嗓、童年照与如今长相、演员的隐藏技能、看似无交集却是同窗。不要用空泛的“高级感”“氛围感”“绝美”。
5. **互动只放大已有画面题眼**：童年照、侧脸、剪影、撞脸对比可做“猜猜”“眼力挑战”；答案页必须完整揭晓并提供额外事实。

### 经验证的选题优先级

| 优先级 | 方向 | 成立条件 | 标题骨架 |
|---|---|---|---|
| P0 | 特征标签盘点 | 特征可在图片中看见，且有明确筛选标准 | 女星的 XX / 自带“XX”的男星 |
| P0 | 成长童年 | 有连续或对照图片，能形成今昔反差 | 从小 X 到大的男星 / 童年照猜明星 |
| P1 | 正向反差 | 公开事实能打破常见印象 | 甜妹的低音嗓 / 明星的隐藏身份 |
| P1 | 互动辨认 | 读者可凭图片判断，答案有信息增量 | 他们曾是队友？ / 眼力大挑战 |
| P2 | 大赏/图鉴 | 同类画面审美稳定、可做 5-8 张 | 女星的 XX 图鉴 / 明星 XX 大赏 |
| P2 | 当期公开动态 | 事件已经官宣，画面和反差都足够强 | 明星也被作业虐 / 演唱会发烤肠？ |

### 不采用的低效结构

- 具体人名 + 单套造型：题眼窄，易变成粉丝向资讯。
- “XX 感”“XX 风”“高颜值气质”：没有可验证的共性，也不能一秒成像。
- 只换形容词的泛盘点：如“绝美女星”“帅气男星”。
- 标题承诺大于素材事实：如“逆袭”“封神”“最强”“天花板”。

## 必经工作流

### 1. 建素材卡

每个候选只围绕一个事实与一组画面，记录：

- 具体对象：女星、男星、童星、歌手、演员或短剧演员。
- 画面题眼：童年照、同款特征、动作、对比图、舞台/日常现场等。
- 事实钩子：公开履历、公开采访、官方活动、已播画面或本人公开内容。
- 来源：实际打开的原文完整 `https://` 链接；标注来源名和文章标题。
- 风险：负面舆情、未经官宣、肖像/图片版权、品牌露出、敏感元素。

只用搜索摘要时，标为“待验证”，不能进入成品池。

### 2. 先做概念去重

与用户提供的已做标题、当前批次、近期开题记录比对以下指纹：

`人物范围 | 共性事实 | 画面题眼 | 叙事角度`

同为“女星原名”“童星现状”“明星撞脸”“男星减肥”“短剧四小花”等，即使更换人物和字面标题，仍是同一概念族。概念族第三次出现时弃用；第二次仅在事实、画面和叙事角度都明显不同且有必要时保留。

### 3. 过四道题眼闸门

候选必须同时回答“是”：

1. 主体是否具体可识别，但标题无需出现真实人名？
2. 首图是否能在 0.5 秒内呈现题眼？
3. 是否有可核验的反差、答案或筛选标准？
4. 落地页是否能用事实兑现标题，而不靠评价词注水？

任一为“否”，回到素材池或放弃。

### 4. 选标题类型，再写副标题

不要反过来先套句式。根据题眼选一个类型：

- **特征标签**：`对象 + 可见特征`。如“男星的花式外号”。
- **反差标签**：`常见印象 + 反常事实`。如“甜妹的低音嗓”。
- **成长对照**：`童年/从小 + 现在的变化`。如“从小帅到大的男星”。
- **关系谜题**：`他们/这群人 + 竟是/曾是 + 关系`。如“他们曾是队友？”。
- **图鉴大赏**：`对象 + 图鉴/大赏/合集`。前提是图组审美统一。
- **互动挑战**：`猜猜/一眼认出/眼力 + 可判断对象`。必须有完整答案。

副标题按“范围 + 2-4 个代表对象 + 具体差异/事实 + 互动收束”扩写。避免把标题原样复述。

## 标题与副标题规格

- 标题：优先 7-9 字，硬上限 10 字；问句必须使用中文问号“？”。
- 副标题：20 字左右，硬上限 25 字；用完整自然句，提供事实而非空洞赞美。
- 标题中的流行词、非字面标签使用中文双引号“”；禁止英文双引号。
- 标题原则上不出现具体艺人姓名。仅当“公开且可验证的当期动态”必须以某人作为事实主体时，才可例外使用，且不得把姓名当作唯一钩子。
- 不用“最”“顶流”“封神”“天花板”“吊打”“碾压”“稳赢”等绝对化或拉踩词。

## 红线与内容安全

- 只使用已官宣或能由权威来源核验的事实；真实学校、经历、亲属关系需复核。
- 不做花边新闻、绯闻、婚恋推测、未成年人恋爱、隐私、负面舆情、疾病卖惨、法制咖相关内容。
- 不给艺人贴可能引发投诉的非大众化标签，不阴阳怪气，不以“丑”“胖”“缺陷”等贬损为卖点。
- 不出现品牌、代言、商务、产品营销词，也避免明显品牌露出图片。
- 互动内容必须有可解释的答案，且避免人名谐音梗。

## 输出模板

每条可用候选按以下格式输出；没有证据的字段写“未满足”，不补造：

```markdown
### 选题 N：标题（X字）

- 子方向：
- 题眼：
- 核心事实：
- 画面方案：首图 / 图组结构 / 需避开的元素
- 概念指纹：人物范围 | 共性事实 | 画面题眼 | 叙事角度
- 去重结论：
- 标题：
- 副标题：（X字）
- 信息源：[已验证] [来源名·文章标题](https://...)
- 风险与核验：
```

批量策划结尾附“自检报告”，只说明实际完成的来源、去重、字数、画面和红线检查。

## 出街前检查

- [ ] 事实与来源已实际打开核验，且链接完整。
- [ ] 标题有具体对象、具体题眼和明确点击理由。
- [ ] 副标题补充了人物/数量/反差，没有重复标题。
- [ ] 标题 <=10 字，副标题 <=25 字，问句与引号使用中文标点。
- [ ] 与已做内容和本批次完成概念级去重。
- [ ] 无八卦、负面、拉踩、未官宣、品牌或敏感风险。
- [ ] 首图能直观兑现标题，图组素材具备肖像与版权使用条件。
